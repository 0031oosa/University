# ПЗ №5: SlowMotion с RAFT

## Описание видео
- Устройство: iPhone
- FPS: 30
- Разрешение: 720×1280
- Длительность: ~4.5 секунды
- Сюжет: статичная камера, пустая улица с домами на фоне,
  курьер на электровелосипеде проезжает поперёк кадра

## Pipeline
- Модель: RAFT-Small (torchvision.models.optical_flow)
- Веса: Raft_Small_Weights.DEFAULT
- Интерполяция: bidirectional flow + linear blending
- Фактор: ×8 (7 промежуточных кадров между каждой парой)
- Device: CUDA (RTX 5060 Ti)

## Параметры запуска
```bash
python slow_motion.py -i IMG_5586.MOV -f 8
```

## Сравнение с Farneback
| | RAFT | Farneback |
|---|---|---|
| Артефакт | Ghosting (двоение силуэта) | «Марево» — размытие границ |
| Границы объекта | Чёткие | Размытые |
| Общее впечатление | Естественнее на статичном фоне | Неприятное размытие при быстром движении |

## Известные ограничения
- 30 FPS — курьер смещается значительно между кадрами,
  что вызывает ghosting при больших значениях t
- Участки однотонного асфальта и неба — flow шумит
  из-за aperture problem
